# BURNRATE 0.6.9

- **Copilot Pulse desktop redesign.** Refreshes the main window and 40px edge tab with bundled **Inter** and **JetBrains Mono** typography, Light and Dark WCAG AA palettes, a frameless topbar, a glowing Hero spend card first on Overview, stacked floating provider cards, and a floating frosted-glass capsule dock for switching between **Overview**, **Spend**, and **Plans**.
- **Premium micro-interactions & custom controls.** Replaces native OS dropdowns in Settings and Plans with custom frosted-glass menus, keeps dragged provider cards 100% opaque with spring FLIP reorder and velocity tilt, adds depth push when opening Settings, and removes the redundant Compact/Comfy density toggle.
