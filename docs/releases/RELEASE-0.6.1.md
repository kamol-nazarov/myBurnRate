# BURNRATE 0.6.1

## Settings → Sources

Scroll through all providers, profiles, and tool scan results in the desktop app,
even at the minimum window size. The Settings tabs and **Done** button stay visible,
and refreshing the tool scan keeps your scroll position.

You can install 0.6.1 on the desktop with your current 0.5.9 or 0.6.0 hub.
