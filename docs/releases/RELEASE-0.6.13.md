# BURNRATE 0.6.13

- **Multi-user hosted Cloud architecture (`BURNRATE_CLOUD_SERVER=1`).** Added physical per-user SQLite isolation (`users/<user_id>/spend.db`), central `auth.db` with 6-digit email OTP verification, 8-character single-use device pairing codes, password reset, verified email changes, instant self-service account deletion, Resend delivery, safe online backups (`python -m spend_app.cloud.backup`), and portable Docker Compose / Caddy / Litestream deployment manifests in `deploy/cloud/`. Local-only and self-hosted Tailnet hub modes remain unchanged.
- **Smooth, zero-reload Settings & Cloud UI.** Added myBurnRate Cloud account flows in **Settings → Computers** (alongside Advanced Self-Hosted Hub), gliding segmented pills, accordion drawers, and zero-reload in-place DOM updates across both **Computers** and **General** tabs, plus fixed General tab pill overflow and toggle switch alignment.
- **Usage & Account Data Audit remediation (15 fixes).** Hardened local credential storage, secret redaction (including `br_cs_*` / `br_cm_*` tokens and local agent run titles), retention pruning, `burnrate hub delete-owner`, and uninstall credential cleanup.
- **Security & performance hardening.** Capped password length before PBKDF2, added per-machine cloud `/api/sync/push` rate limiting, blocked email CRLF header injection, evicted deleted tenant caches, bounded in-memory throttle/last-seen maps, enabled 15-second quantized cloud read caching with `BoundedReadExecutor`, and fixed non-root Docker volume ownership in `deploy/cloud/compose.yaml`.
