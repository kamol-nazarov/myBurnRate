# BURNRATE 0.6.3

- **Codex speed in Limits.** The local Codex card shows the saved Standard, Fast, or Ultrafast preference.
  Individual chats can select another speed. API-equivalent pricing uses the recorded usage and rate cards.
- **More pricing coverage.** GPT-6.2 Astra and Sol now have Standard API-equivalent rates. The release also
  covers recorded Gemini aliases and earlier DeepSeek V4.1 Flash and Grok 4.7 usage with published rates.
- **Install & restart for the managed Python desktop.** Future signed-wheel updates can install from
  **Settings → General → Check for updates**. The updater verifies the download, backs up local data,
  installs the wheel, and reopens the desktop. Install 0.6.3 once to add this capability.
